# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through a [GitHub private security advisory](https://github.com/MamdouhAlsaodi/EstateFlow/security/advisories/new). Include a clear description, affected files or versions, reproduction steps, and potential impact.

Do **not** open a public issue containing credentials, tokens, private keys, connection strings, customer data, or other sensitive data. If a private advisory is unavailable, contact the repository owner through GitHub without including sensitive material in the initial message.

This is an in-progress Training Demo. Reports are reviewed on a best-effort basis; no response-time or production-support commitment is made.

## Scope

Report vulnerabilities in the repository's code, configuration, documentation, and supplied local/demo infrastructure. Do not test against systems, accounts, or data that you do not own or have explicit permission to use.
