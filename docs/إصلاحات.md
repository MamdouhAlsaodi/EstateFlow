> سجل تنفيذي متسلسل للإصلاحات والـcorrections. لا نبدأ بندًا جديدًا قبل أن يصبح البند الحالي **مكتملًا** مع دليل تحقق مستقل.

## قواعد العمل

1. لكل بند مالك ونطاق محدود وملفات مسموحة.
2. الحالات الوحيدة: `معلق` → `قيد التنفيذ` → `بانتظار التحقق` → `مكتمل` أو `محجوب`.
3. لا يعني تقرير العامل أن البند مكتمل؛ يلزم فحص diff وتشغيل الاختبارات المناسبة.
4. عند اكتشاف defect أثناء التحقق، يُسجل كبند جديد ولا يُوسّع البند الحالي بصمت.
5. لا commit أو push أو deploy ضمن هذا السجل إلا بتوجيه صريح من ممدوح.

## حالة النظام

**متوقف بالكامل بأمر ممدوح — 2026-08-04.**

يشمل هذا التوقف جميع أعمال EstateFlow: التنفيذ، workers، verification، quality، إصلاحات الطابور، والـcommit/push. لا يُستأنف أي بند تلقائيًا؛ يلزم توجيه صريح جديد من ممدوح.
